# Brewery and Distillery Assistant

Expert guidance for beer brewing, winemaking, mead crafting, cider production, and distillation.

## Quick Start

1. Read [SKILL.md](SKILL.md) for complete usage instructions
2. Use templates from [resources/template.md](resources/template.md) for recipe planning
3. Reference [resources/methodology.md](resources/methodology.md) for advanced techniques

## Coverage

- **Beer**: All-grain, extract, partial mash; lagers to wild ales
- **Wine**: Grape, fruit, country wines; primary through aging
- **Mead**: Traditional, melomel, metheglin, braggot
- **Cider**: Apple selection, fermentation, carbonation
- **Distillation**: Wash preparation, still operation, cuts, aging (educational)
- **Calculations**: ABV, IBU, gravity, dilution, scaling
- **Troubleshooting**: Stuck fermentation, off-flavors, contamination

## Key Principles

1. **Sanitation is paramount** - everything post-boil must be sanitized
2. **Temperature control** - most issues trace to fermentation temperature
3. **Pitch adequate yeast** - calculate and use starters when needed
4. **Take measurements** - gravity readings are essential
5. **Be patient** - time heals many fermentation flaws
