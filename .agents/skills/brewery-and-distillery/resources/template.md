## Workflow Checklist

```
Fermentation Project Progress:
- [ ] Define style/goal and key parameters
- [ ] Design recipe with calculations
- [ ] Prepare water and sanitize equipment
- [ ] Execute production (mash/crush/prepare)
- [ ] Pitch yeast with proper oxygenation
- [ ] Monitor and control fermentation
- [ ] Condition, clarify, and package
- [ ] Document results for reproducibility
```

## Calculation Worksheets

### ABV Calculator

**Simple formula** (accurate to ~0.3%):
```
ABV = (OG - FG) × 131.25
```

**Accurate formula** (for high-gravity):
```
ABV = [76.08 × (OG - FG) / (1.775 - OG)] × (FG / 0.794)
```

**Example:**
- OG: 1.065
- FG: 1.012
- ABV = (1.065 - 1.012) × 131.25 = **6.96%**

### Attenuation Calculator

**Apparent attenuation:**
```
AA% = (OG - FG) / (OG - 1.000) × 100
```

**Example:**
- OG: 1.050
- FG: 1.010
- AA% = (1.050 - 1.010) / (1.050 - 1.000) × 100 = **80%**

### IBU Calculator (Tinseth)

```
IBU = (oz hops × alpha acid% × utilization × 7489) / gallons

Utilization factors by boil time:
60 min: 0.252
45 min: 0.219
30 min: 0.177
20 min: 0.141
15 min: 0.105
10 min: 0.074
5 min: 0.046
0 min (whirlpool): ~0.02
```

**Example:**
- 1 oz Centennial at 10% AA, 60 min boil, 5 gallons
- IBU = (1 × 10 × 0.252 × 7489) / 5 = **37.7 IBU**

### Pitch Rate Calculator

```
Cells needed = (mL wort) × (°Plato) × (pitch rate)

Pitch rates:
- Ale: 0.75 million cells/mL/°P
- Lager: 1.50 million cells/mL/°P
- High gravity (>1.080): Add 25-50%

°Plato ≈ (SG - 1) × 1000 / 4
```

**Example:**
- 19 liters at 1.060 (15°P) ale
- Cells = 19,000 × 15 × 0.75 = **213 billion cells**

### Starter Size Calculator

```
Growth factor = Final cells / Initial cells
Starter size needed = (Cells needed - Viable cells) / (Growth factor × Viable cells) / (cells/mL growth rate)

Without stir plate: ~1.5 billion cells/mL/day
With stir plate: ~3.0 billion cells/mL/day
```

**Simplified:**
- 1L starter on stir plate doubles ~100B cells → ~200B
- 2L starter on stir plate can produce ~300-400B from fresh pack

### Priming Sugar Calculator

```
Grams of sugar = Volume (L) × (Target CO2 - Residual CO2) × 4

Residual CO2 at fermentation temp:
60°F: 1.05 vol
65°F: 0.96 vol
70°F: 0.88 vol
75°F: 0.80 vol
```

**Example:**
- 19L batch, fermented at 68°F, target 2.5 volumes CO2
- Sugar = 19 × (2.5 - 0.92) × 4 = **120g corn sugar**

### Dilution Calculator (Spirits)

```
V2 = V1 × (ABV1 / ABV2)

Water to add = V2 - V1
```

**Example:**
- 500 mL at 65% ABV, target 40% ABV
- V2 = 500 × (65/40) = 812.5 mL final
- Add **312.5 mL** distilled water

### Strike Water Temperature

```
Strike temp = Target mash temp + [(Grain weight × 0.2) / Water volume] × [Target - Grain temp]

Simplified rule of thumb:
Strike temp ≈ Target mash temp + 10-12°F (for typical ratios)
```

## Troubleshooting Quick Reference

### Stuck Fermentation Checklist

- [ ] **Temperature check**: Is it in optimal range for yeast strain?
- [ ] **Gravity check**: What is current gravity vs. expected FG?
- [ ] **Yeast check**: Was pitch rate adequate? Starter made? Fresh yeast?
- [ ] **Nutrient check** (mead): Were nutrients added per schedule?
- [ ] **Fermentability check**: Mash temp? High dextrin content expected?
- [ ] **Action**: Warm, rouse yeast, repitch if needed

### Off-Flavor Decision Tree

```
Taste/smell issue?
├── Green apple/cidery → Acetaldehyde → More conditioning time
├── Butter/butterscotch → Diacetyl → Diacetyl rest (warm 3-5 days)
├── Cooked corn → DMS → Longer boil, faster cooling next time
├── Hot/solvent → Fusel alcohols → Ferment cooler next time
├── Band-aid/medicinal → Chlorophenol → Use campden for chlorine
├── Rotten eggs → Sulfur → Time + healthy yeast; normal in lagers
├── Sour/vinegar → Contamination → Assess severity; may be unsalvageable
└── Cardboard/papery → Oxidation → Minimize oxygen exposure; reduce headspace
```

### Pre-Packaging Checklist

- [ ] Gravity stable for 3+ consecutive days
- [ ] No airlock activity
- [ ] Clarity acceptable (or plan for fining)
- [ ] Off-flavors resolved (condition longer if needed)
- [ ] Carbonation method decided
- [ ] Packaging equipment sanitized
